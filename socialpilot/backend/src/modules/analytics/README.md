# Analytics Module — `/api/analytics`

Dashboard analytics and AI-generated insights. Provides overview metrics, lead data, growth trends, and natural-language business insights.

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/analytics/overview` | Dashboard overview metrics (comments, DMs, leads, deals, revenue) |
| GET | `/api/analytics/leads` | Lead metrics by category and source |
| GET | `/api/analytics/growth` | Daily lead growth over the last 30 days |
| GET | `/api/analytics/insights` | Get stored AI insights for a period |
| POST | `/api/analytics/insights/generate` | Generate fresh AI insights from conversation data |

## Architecture

- Overview returns aggregated counts and AI reply rates
- Insights are generated by the AI service analyzing actual conversation data (works when data exists)
- Insights are cached in the `Insight` model with categories: `common_questions`, `peak_times`, `customer_sentiment`, `lead_sources`, `performance_weekly`
- Trend indicators: `up`, `down`, `stable`
